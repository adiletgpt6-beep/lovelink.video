# LoveLink — гайд по стилю рекламных видео

Источник правды — реальные репозитории продукта (`LoveLink_front`, `FeelLink` (view.lovelink.my),
`FeelLinkEdit` (edit.lovelink.my), `LoveLink_Password`). Все цвета, тексты и компоненты
в роликах воспроизведены по их исходному коду, а не придуманы.

## Формат и безопасные зоны

* 1080×1920, 9:16, 30 fps, H.264 (yuv420p, CRF 18) + AAC 192 kbps.
* Длительность 38–43 с (цель 30–45 с).
* Безопасная зона: сверху ≥ 220 px, снизу ≥ 420 px (область подписи/иконок Reels и TikTok),
  справа ≥ 110 px. Субтитры рисуются с `bottom: 300–470 px`, бейджи шагов — не ниже y = 1480.
* Первые 2–3 секунды каждого ролика — визуальный крючок (крупный текст / контраст / движение).

## Субтитры

Пословная синхронизация по таймкодам ElevenLabs (`character_start_times_seconds`).
Активное слово подсвечивается розовым (`#F84888` на светлом, `#FDA4C4` на тёмном),
следующие слова — 72 % прозрачности. Стили: `pill` (размытая тёмная плашка), `clean`
(текст с тенью), `boxed` (чёрный прямоугольник, Unbounded — для VIDEO-003).

## Голос

ElevenLabs, модель `eleven_v3`, язык `ru`, нормализация громкости `loudnorm I=-16 LUFS`.
Голоса по роликам: 001 Sarah, 002 Eric, 003 Brian, 004 Alice, 005 Jessica (все premade,
доступные по текущему ключу). Музыка приглушается до ~0.14–0.16 во время речи.

## Музыка

Сгенерирована процедурно (`scripts/music.py`, numpy) — собственные композиции без
сторонних сэмплов, лицензионных ограничений нет. Темп и настроение подобраны под ролик:
66 BPM фортепиано/пэд (001), 104 BPM лёгкий продукт-грув (002), 124 BPM энергичный (003),
84 BPM тёплый 6/8 (004), 128 BPM поп (005).

## Что нельзя обещать (проверено по коду)

* Нет мобильного приложения — только веб (lovelink.my, edit.lovelink.my, view.lovelink.my).
* Пароль подарка — 6 цифр (буквы появятся только после исчерпания числового диапазона).
* Бесплатно: готовые ссылки на шаблоны (гость — 2, после регистрации — 5) и один бесплатный
  персональный подарок; дальше тарифы Start $10 / Business $50 / Pro $100.
* Хранение страниц — 30 лет (текст тарифов). Редактирование — безлимитное.
* Редактор текста подарка, ИИ-помощник, клонирование, код для редактирования клиенту — только
  в платных тарифах.
