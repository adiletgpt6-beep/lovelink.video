## Ограничения этой сессии (важно)

* **Реальные скриншоты сайта не использованы** — домены `lovelink.my`, `*.vercel.app` недоступны из сессии,
  а запуск `next dev` в чужих репозиториях заблокирован авторежимом. Все экраны — точные
  React-реконструкции по исходному коду (Tailwind-классы и тексты скопированы из репозиториев).
  См. HANDOFF.md → «Как заменить реконструкции на реальные записи».
* Голоса — premade-голоса ElevenLabs (ключ не имеет права `voices_write`, поэтому нельзя добавить
  нативные русские голоса из библиотеки). Прослушать и при желании заменить голос — одна команда
  (`node scripts/tts.mjs --force` после правки `vo-scripts.json`).
* Внешнее хранилище (R2) из окружения относится к другому проекту (`balago-live-sources`) и
  недоступно из сессии, поэтому MP4 (по ~5–12 МБ) закоммичены прямо в репозиторий.
